# Проверка кода

Независимое автоматизированное ревью и регрессионные тесты.

Проверены бинарный формат, границы буферов, RTT/SRTT/jitter/loss,
состояния ответов, ограниченные контейнеры, UDP-сокеты и скрипты запуска.

Исправлены замечания: повторная метка при переиспользовании sequence,
сохранность CSV при ошибке предварительной проверки и параметры отчёта.
Runner находит бинарники Visual Studio в Release/Debug и читает версию
компилятора из CMake. Добавлен запуск клиента и сервера одной командой.

CI: Windows, Linux и macOS; на Linux также AddressSanitizer + UBSan.
[Проверки исходной реализации](https://github.com/Copilot82/mirea-udp-latency/actions/runs/39405143959)
завершены успешно на всех трёх платформах.
