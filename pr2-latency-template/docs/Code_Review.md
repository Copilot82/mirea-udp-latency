# Ревью

Независимое автоматизированное ревью агента Codex от 2026-10-20.
Это не ревью участника команды и не человеческое одобрение PR.

Проверены protocol/telemetry/transport, приложения, тесты и скрипты.
Замечания и исправления:

1. Равная метка времени после вытеснения записи позволяла сопоставить старый
   PONG с новым sequence. В обычном CLI интервал не менее 1 мс исключал этот
   путь, но библиотека теперь требует строго возрастающее время отправки.
   Регрессия Evicted sequence cannot reuse the same timestamp: RED -> GREEN.
2. Runner с --overwrite удалял CSV до проверки бинарников. Все предварительные
   проверки перенесены до удаления. Регрессия runner_preflight_failure_preserves_existing_measurements: RED -> GREEN.
3. Генератор отчёта имел фиксированные 50/200 при настраиваемом runner.
   Число и интервал теперь берутся из метаданных, количество сверяется с CSV.
4. Для runner в MSVC нужен сбор версий другим способом; ограничение указано
   в Experiment_Config.md. C++ приложения используют Winsock на Windows.

Debug и Release CTest проверяют Catch2 и реальные UDP-сценарии, а также
независимый анализ CSV. UBSan проверен отдельно. Локальный ASan в Apple Clang 17
на macOS 26.4.1 зависал в инициализации runtime до main (рекурсивная блокировка
AsanInit/InitializeShadowMemory, подтверждено sample). Процесс остановлен;
локальное прохождение ASan не заявляется. ASan+UBSan вынесены в Linux CI.

Ревью участника команды отслеживается отдельным открытым issue #3.
